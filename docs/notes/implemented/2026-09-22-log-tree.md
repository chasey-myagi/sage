# Log：只追加的树

## Problem

会话需要一份永不改写的历史。旧设计靠持久化水位记住写到第几条，崩溃后续写。水位和文件一旦分叉，就会重放或漏条。entry 的种类还会继续增加，内核如果认识每一种的语义，Log 与 View 的边界就守不住。

## Decision

Log 是只追加的树。每条 entry 带 `id` / `parentId` / `seq` / `at` / `kind` / `payload`，外加可选且不透明的 `details`。追加先 `writeSync` 再 `fsyncSync`，成功之后才进入内存。打开时最后一行解析失败就丢掉，并把这个尾巴从文件里截掉，记 `torn`；`torn` 不参与下一条 `seq`。中间行损坏抛 `LogCorruptedError`（消息含行号）。kind 在 import 时注册，未注册的 kind 抛 `UnknownEntryKindError`（消息含 kind 名），不跳过。校验失败抛 `InvalidEntryError`，文件不写。

`leaf` 本身是一条 entry。`leaf()` 按 seq 扫描得出：`leaf` 把指针指到 `target`，其他 kind 把指针指到自己。`path` 从指针沿 `parentId` 走回根，链上不含 `leaf` entry。内核自带 `message`、`request_header`、`view_epoch`、`model_change`、`manifest`、`undo`、`leaf`、`terminal` 八种 kind，只做形状校验，不带 reducer。`replay` 按 seq 调用注册表里的纯 reducer，没有 reducer 的 kind 跳过。悬空 tool call 的两句模型可见文本由 `synthesizeToolResult` 给出，不扫描历史。清单由 `scripts/gen-log-manifest.mjs` 从 `entryKinds()` 生成，`check:log-manifest` 做新鲜度检查，并接进 `pnpm check`。

## Alternatives considered

不要 HWM。水位是文件旁边的第二份真相。崩溃刚好卡在「字节写了、水位没推进」或反过来时，两边对不齐。先落盘再进内存之后，完整的行就是已经接受的历史，下一条 seq 等于读进来的条数，不需要另一个只增计数器。

leaf 做成 entry，不做成指针文件。指针文件是另一份可改写状态，和只追加冲突，也没法单靠日志重建「指针曾经指向过哪」。把移动指针记成一条 entry 之后，分支不复制任何历史，回放就能还原每一次移动。

未知 kind 拒绝，不跳过。跳过会把读不懂的事实悄悄丢掉，同一份日志在不同构建里算出不同的历史。读到本构建不认识的 kind 就报出名字并拒绝整份重建，让调用方升级或丢弃会话，而不是带着缺口继续。

## Consequences

磁盘是内存的超集。`writeSync` 失败时这条不进内存，`leaf()` 不变。撕掉的最后一行必须从文件里截掉，否则下一次追加会粘在半行后面，重开时整行被当成新的撕裂丢掉。`torn` 只说明发生过撕裂。

`@sage/provider/contract` 在这条分支上还没有 `Message`、`ModelRef`、`ToolResultBlock`（#3 未合入）。`message` 的 `{ role, content }`、模型引用和合成的 tool result 用同形结构类型检查，没有对 provider 做 value import。#3 合入后应改成 `import type`。

本票不投影、不扫描悬空 tool call。合成结果要进历史，得由调用方自己 append。L8 的 `responseModel` / `responseId` / `api` / `traceId` 不是 `message` 的必填字段，可以放在 payload 的额外字段或 `details` 里。

同一 `sessionId` 的 `append` 必须串行。实现是同步的，单线程里不会交错；并发调用方要自己排队。`vitest.config.ts` 的 include 加上了 `packages/**/test/**/*.test.ts`，否则 `pnpm test` 只跑 scripts，核心测试进不了 `pnpm check`。

## Testing

`pnpm check` 退出码为 0，其中 `pnpm check:log-manifest` 在清单与注册表一致时为 0、不一致时非 0。测试覆盖：100 条追加与重开、第 57 行半行撕裂后得到 56 条且下一条 seq 为 56 并再次落盘、第 30 行非法 JSON 抛出带行号的错误、未注册 kind 抛出带名字的错误且不跳过、校验失败不写文件、`leaf` 分支不复制历史、`replay` 按 seq 折叠、`writeSync` 抛错时内存与 leaf 不变、两种悬空 tool 文本。
